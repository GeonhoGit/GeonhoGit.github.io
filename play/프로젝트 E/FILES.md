# 프로젝트 E · K-직장인 퇴사 시뮬레이터 파일 안내

클릭과 자동 수입으로 퇴사 자금을 모으는 브라우저 게임입니다. [`index.html`](./index.html)을 엽니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조, 스타일, 게임 로직이 모두 들어 있습니다. 클릭 수익, 업그레이드, 주식, 미니게임, 퇴사·환생, 브라우저 저장 기능도 이 파일에서 처리합니다. |
| `ads.txt` | 광고 제공자 확인용 텍스트 파일입니다. |
| `README.md` | 게임 소개와 실행 방법을 적은 기존 설명서입니다. 이 폴더의 실제 실행 파일 이름은 `index.html`입니다. |
| `FILES.md` | 이 파일별 역할 안내문입니다. |
