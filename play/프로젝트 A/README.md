# 차곡냥

냥이의 작은 상자 — 같은 고양이 네 마리를 한 상자에 모으는 퍼즐 게임입니다.

[웹에서 플레이하기](https://geonhogit.github.io/chagoknyang/)

180개 퍼즐과 무한모드, 진행 자동 저장, BGM, 홈 화면 설치와 오프라인 플레이를 지원합니다.

휴대폰에서는 터치하고 PC에서는 클릭하거나 Tab·Enter로 조작합니다. 진행은 사용하는 브라우저에 저장되며 Android 앱과 자동 동기화되지 않습니다.

이 저장소는 웹 배포 파일을 관리합니다. GitHub Pages는 main 브랜치의 루트에서 배포합니다.
