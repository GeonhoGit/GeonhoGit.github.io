# 프로젝트 G · 지워지지 않은 밤 파일 안내

중고 컴퓨터에 남은 기록을 조사하는 브라우저 추리 게임입니다. [`index.html`](./index.html)을 엽니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면의 진입점으로, 스타일과 `app.js` 모듈을 불러옵니다. |
| `style.css` | 가상 데스크톱, 파일 창, 단서·퍼즐 화면의 스타일입니다. |
| `app.js` | 시작 화면, 가상 파일 열기, 퍼즐 조작, 엔딩 표시와 자동 저장 등 화면 동작을 처리합니다. |
| `content.js` | 조사 대상 파일 내용, 이야기 텍스트, 결말과 사건 해설 데이터를 담습니다. |
| `domain.js` | 진행 상태의 기본값, 단서 접근 조건, 정답 판정, 결말 선택과 저장 데이터 검증 규칙을 담습니다. |
| `archive-box.png` | 보관 상자 이미지 자료입니다. 현재 배포 코드에서는 직접 참조하지 않습니다. |
| `repair-receipt.png` | 수리 영수증 이미지 자료입니다. 현재 배포 코드에서는 직접 참조하지 않습니다. |
| `FILES.md` | 이 파일별 역할 안내문입니다. |
