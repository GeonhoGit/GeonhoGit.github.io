# 프로젝트 F · 작은 웹 실험들 파일 안내

여러 작은 웹 도구와 게임을 모은 폴더입니다. 맨 위의 [`index.html`](./index.html)이 목록을 보여 주며, 선택한 항목을 같은 페이지의 `iframe`에서 엽니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 여덟 실험의 선택 화면과 실행 화면 전환을 처리합니다. |
| `계산기/index.html` | 수입·지출 항목을 표에 추가하고 합계를 계산하는 실험입니다. HTML 안에 화면과 동작 코드가 들어 있습니다. |
| `돌림돌림돌림판/index.html` | 버튼을 누르면 목표 숫자가 나올 때까지 난수를 반복 생성하고, 시도 횟수를 개발자 콘솔에 출력하는 실험입니다. 화면에 돌림판 그림은 없습니다. |
| `문서(div)/index.html` | `div` 요소로 원천징수 신고서 형태를 구성한 문서 실험입니다. |
| `문서(div)/표만들기.css` | `div` 문서의 표, 간격, 테두리 등 인쇄물 같은 모양을 지정합니다. |
| `문서(div)/js.js` | `div` 문서의 반복 칸과 간격 요소를 생성합니다. |
| `문서(table)/index.html` | HTML `table`로 원천징수 신고서 형태를 만든 첫 번째 실험입니다. |
| `문서(table)1/index.html` | HTML `table`로 세금계산서 형태를 만든 두 번째 실험입니다. |
| `박스피하기/index.html` | 장애물 피하기 게임의 캔버스와 시작·종료 화면입니다. |
| `박스피하기/game_css.css` | 게임 화면과 팝업의 배치·색상을 지정합니다. |
| `박스피하기/js.js` | 게임 시작, 장애물 이동, 충돌 판정, 시간·난이도 처리를 담당합니다. |
| `복권 번호/index.html` | 0–9 숫자 여섯 자리를 무작위로 뽑아 전체 또는 각 조의 번호를 보여 줍니다. |
| `복권 번호/index.css` | 복권 번호 화면의 스타일입니다. |
| `점심 뽑기/index.html` | 점심 메뉴를 무작위로 고르는 화면과 동작이 들어 있습니다. |
| `FILES.md` | 이 파일별 역할 안내문입니다. |

일부 실험은 외부 CDN에서 jQuery를 불러오므로 인터넷 연결 상태에 따라 동작이 달라질 수 있습니다.
