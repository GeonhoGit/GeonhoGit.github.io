# 프로젝트 D · 고누 파일 안내

한국 전통 보드게임 고누의 브라우저 버전입니다. [`index.html`](./index.html)에서 로컬 대국과 경력 모드를 실행할 수 있습니다. 온라인 대국은 별도의 서버가 필요합니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임판과 메뉴, 로컬·경력·온라인 대국 화면의 기본 구조입니다. |
| `styles.css` | 게임판, 말, 메뉴, 반응형 화면의 스타일입니다. |
| `app.js` | 고누 규칙·턴·말 이동, 화면 갱신, 경력 진행 및 온라인 접속 클라이언트를 담당합니다. |
| `online-server.cjs` | Node.js로 정적 파일을 제공하고 WebSocket 방 생성·참가·대국 상태 전달을 처리합니다. GitHub Pages에서는 실행되지 않습니다. |
| `VERSION` | 이 배포본의 버전 번호 `0.1.3`을 기록합니다. |
| `FILES.md` | 이 파일별 역할 안내문입니다. |

온라인 대국을 로컬에서 시험하려면 이 폴더에서 `node online-server.cjs`를 실행하고 출력되는 로컬 주소를 여세요.
