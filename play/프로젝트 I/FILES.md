# 프로젝트 I · 달빛골 파일 안내

농사와 낚시, 동물 이웃과의 교류를 즐기는 생활 게임입니다. [`index.html`](./index.html)을 엽니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면과 조작 요소를 표시합니다. |
| `style.css` | 화면 스타일입니다. |
| `world.js` | 마을과 게임 데이터를 정의합니다. |
| `engine.js` | 게임 규칙과 상태를 처리합니다. |
| `render.js` | 캔버스 화면을 그립니다. |
| `app.js` | 입력과 화면 동작을 연결합니다. |
| `FILES.md` | 이 파일 안내문입니다. |
