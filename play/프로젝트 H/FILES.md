# 프로젝트 H · 웹 게임 파일 안내

현재 이 폴더에는 마우스로 장애물을 피하는 **박스 피하기** 게임이 들어 있습니다. [`index.html`](./index.html)을 엽니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 캔버스와 게임 시작·종료 팝업, 플레이 안내를 표시합니다. |
| `game_css.css` | 게임 화면, 현재 난이도·시간 표시와 팝업의 스타일입니다. |
| `js.js` | 마우스 조작, 장애물 애니메이션, 충돌 판정, 시간·난이도와 재시작을 처리합니다. |
| `FILES.md` | 이 파일별 역할 안내문입니다. |
