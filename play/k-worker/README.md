# 💻 K-직장인 퇴사 시뮬레이터 (K-Worker Resignation Simulator)

> "모니터를 부수고 당당하게 사표를 던지는 그날까지!"

**K-직장인 퇴사 시뮬레이터**는 목표 자금 **100억 원**을 모아 사장님 면전에 사표를 던지는 것을 목표로 하는 유쾌한 방치형/클리커 웹 게임입니다. 순수 HTML, CSS, JavaScript(Vanilla)로 제작되었으며, 브라우저만 있으면 어디서든 즐길 수 있습니다.

## ✨ 주요 기능 및 특징

- 🖱️ **클리커 & 방치형 수익 시스템**
  - '코딩 노가다'를 클릭해 돈을 벌고, '매크로 마우스'부터 '사장님 약점 파일'까지 다양한 야매 업무 툴을 업그레이드해 초당 자동 수입(CPS)을 늘려보세요.
- 📈 **K-거래소 (하이리스크 노리턴)**
  - 실시간 돌발 뉴스에 따라 주가가 요동칩니다. 상성전자, 화성갈끄니까, 진돗개코인 등 다이나믹한 시장에서 타이밍을 노려 풀매수/전량매도 하세요.
- 🎲 **다양한 미니게임**
  - **사내 망 해킹**: 3자리 숫자를 맞추는 숫자 야구 룰의 해킹 미니게임으로 비자금을 탈취하세요.
  - **월급루팡 슬롯머신**: 일확천금을 노리는 짜릿한 슬롯머신!
  - **스피또**: 5천원으로 최대 1,000만 원 당첨을 노려보세요 (파산 주의☠️).
- ⚠️ **돌발 결재 서류 이벤트**
  - 업무 중 무작위로 날아오는 결재 서류를 클릭해 보너스 자금을 획득하세요. 단, 가끔 일반 서류로 위장한 함정(실수) 서류가 있으며, 이를 누르면 시말서를 쓰고 자산이 차감됩니다.
- 🔄 **환생 (Prestige) 시스템**
  - 100억 원 달성 시 통쾌한 엔딩과 함께 사표를 던지고, '경력직 보너스'를 획득하여 수입이 뻥튀기된 채로 새롭게 시작할 수 있습니다.

## 🚀 실행 방법

별도의 설치나 서버 세팅이 필요하지 않습니다.
1. 프로젝트를 다운로드하거나 클론합니다.
2. 브라우저(Chrome, Edge 등)에서 `main.html` 파일을 엽니다.
3. 열심히 클릭하고, 투자하고, 퇴사 자금을 모으세요!

## 💾 세이브 지원

브라우저의 `localStorage`를 활용하여 1분마다, 혹은 주요 액션마다 게임이 자동 저장됩니다. 브라우저를 닫았다가 다시 열어도 진행 상황이 유지되며 오프라인 방치 보상도 주어집니다.

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **기타**: Web Audio API (효과음 구현), Canvas API (주식 차트 렌더링)
